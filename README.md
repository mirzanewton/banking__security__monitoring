# Banking Security Monitoring & Threat Detection

**[View live dashboard](https://mirzanewton.github.io/banking_security_monitoring/reports/dashboard.html)**

A Python tool that analyses authentication logs, flags suspicious login
patterns, and shows the alerts on a SIEM-style HTML dashboard.

> The sample log is **synthetic** (generated by `generate_sample_logs.py`) so
> the project can be run and shared without any real banking data.

## What it detects

| Rule | Severity | Trigger |
|------|----------|---------|
| `BRUTE_FORCE` | HIGH | 5+ failed logins for the same user from the same IP within 120 s |
| `PASSWORD_SPRAYING` | HIGH | One IP fails against 4+ different accounts within 10 min |
| `SUCCESS_AFTER_FAILURES` | CRITICAL | A login succeeds right after a brute-force burst (possible compromise) |
| `OFF_HOURS_LOGIN` | MEDIUM | Successful login outside 06:00-22:00 |

Thresholds are constants at the top of `detector.py`.

## Run it

Requires Python 3.8+ and no extra packages.

```bash
python generate_sample_logs.py          # creates logs/sample_auth.log
python dashboard.py logs/sample_auth.log
```

Then open `reports/dashboard.html` in a browser. Raw alerts are saved in
`reports/alerts.json`.

## Log format

```
2026-11-01 11:00:32 LOGIN FAILED user=admin ip=203.0.113.50
```

## Project structure

```
detector.py               parsing + detection rules
dashboard.py              runs the detector, writes JSON + HTML dashboard
generate_sample_logs.py   creates fake test data with planted attacks
logs/                     input logs
reports/                  generated output
```

## Limitations and ideas for next steps

- Rules are fixed thresholds; they will miss slow, low-volume attacks.
- Only one simple log format is supported.
- Next steps: GeoIP lookups, support for real `auth.log` / Windows event
  formats, email alerts, and mapping rules to MITRE ATT&CK techniques.
